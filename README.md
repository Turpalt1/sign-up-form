Проект: Форма регистрации
Введение
Этот проект призван дать вам возможность применить на практике некоторые новые знания, полученные на последних уроках. На этот раз это форма регистрации для вымышленной службы.

Назначение
Шаг 1: Подготовка и планирование
Настройте свой репозиторий Git (при необходимости освежите память, обратитесь к предыдущим проектам).
Настройте свои HTML и CSS файлы, добавив в них фиктивный контент, чтобы убедиться в правильности всех ссылок.
Скачайте полноразмерную копию файла дизайна и получите общее представление о том, как вам нужно будет расположить элементы в вашем HTML-документе.
Шаг 2: Сбор активов
Дизайн имеет большое фоновое изображение, поэтому найдите и скачайте картинку, которую хотите использовать для этого раздела. Изображение, использованное в дизайне, можно найти на unsplash.com , но вы можете выбрать и своё собственное. Не забудьте указать автора изображения!
Выберите внешний шрифт для раздела «логотип». Мы использовали Norse Bold , но вы можете использовать любой шрифт по своему вкусу.
Для боковой панели с изображениями мы использовали логотип Одина .
Шаг 3: Несколько советов!
Как именно вы подойдете к этому проекту, в основном зависит от вас, но разумно начать с создания структуры страницы, а затем поочередно приступать к различным разделам.
Область за логотипом «ODIN» представляет собой блок div с темным, но полупрозрачным фоном. Это улучшает читаемость текста на фоне насыщенного изображения.
Цвет, который мы выбрали для кнопки «Создать учетную запись», похож на оттенки фонового изображения. А именно, это #596D48.
По умолчанию поля ввода имеют очень светлую рамку ( #E5E7EB), но мы добавили 2 варианта. Для начала, поля ввода пароля должны иметь красную рамку, если они содержат неверный пароль. Это можно обработать с помощью :user-invalidпсевдокласса, который вы изучили в предыдущем уроке.
Другой вариант — выделенный элемент ввода, который должен иметь синюю рамку и едва заметную тень. Это можно сделать с помощью :focusпсевдокласса, о котором вы узнали на предыдущем уроке.
Не беспокойтесь о том, чтобы ваш проект хорошо выглядел на мобильных устройствах. Адаптивный дизайн рассматривается только позже в учебной программе.
Для проверки соответствия полей ввода пароля друг другу требуется JavaScript. Использование JavaScript для проверки форм будет рассмотрено в следующем уроке. А пока просто проверяйте каждое поле отдельно.
